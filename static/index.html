Clonar privado para tópico

Copia mensagens de uma conversa privada para um tópico específico de um supergrupo (fórum).

O que conta como mensagem recebida?
  • Apenas recebidas — copia somente mensagens que a outra pessoa enviou para você no privado (texto, foto, vídeo, áudio, documento, sticker, etc.).
  • Todas — inclui também as mensagens que você enviou na mesma conversa.
  • Encaminhadas — se alguém te enviou uma mensagem encaminhada no privado, ela entra como recebida (o conteúdo é copiado; o autor original continua oculto no destino, como nas outras cópias).
  • Não são copiadas — avisos de serviço do Telegram (ex.: “fulano entrou”, “mensagem apagada”, “fixou mensagem”).
  • Incremental — nas próximas execuções, copia só mensagens novas desde a última cópia deste par (chat + grupo + tópico + filtro escolhido).
